# NAS预览与文件夹预生成（2026-10-30）

网络路径（UNC或映射网络驱动器）预览优先用完整路径、文件大小和UTC修改时间构建路径缓存标识。命中时只读属性和本地PNG，不打开模型内容；未命中则复制一份到本机临时目录，原内容SHA缓存和渲染在本机完成。源属性生成前后不一致时不写路径缓存。路径保留大小写，避免大小写敏感NAS上的同名碰撞。所有路径PNG仍计入原256MiB淘汰预算，无驻留服务。

传统与原生Store缩略图处理器尝试从IStream.Stat获得原网络路径。获得可访问原路径时可用上述优化；Windows仅提供匿名流时保留完整复制回退，不能保证资源管理器所有请求都跳过网络读取。未改变NAS或Windows清理策略。

管理器“文件夹预生成”及预览页“文件夹 / Folder”打开独立进度窗口，只处理当前文件夹，不递归；小文件优先，串行生成，显示当前文件、完成/失败及异常说明。取消会停止排队并取消worker，终止并等待其进程树退出；目录枚举会检查取消，单次底层文件系统调用仍可能等待Windows超时。任务期间关闭窗口先取消。强制更新会移除该网络路径的索引，重新读内容，适用于内容变更但大小和修改时间均未变化的特殊情况。普通打开也受此元数据缓存限制。

桌面版预生成后再请求Windows缓存；先强制生成256像素，小尺寸使用缩放缓存，减少重复提取。Store包没有独立refresher时只预热本地预览缓存，随后通知目录更新，由资源管理器请求图片。没有把“生成中”图片写入Windows缓存，也没有给每个文件图标加入动态覆盖层。

验证：两份真实NAS样本1.stl（13.4MiB）、002实验（无牙.3mf（17.8MiB）直接worker首次4.010/1.014秒，命中0.279/0.236秒。资源管理器强制提取两次都成功，再次请求0.928/0.826秒。单文件Windows三尺寸刷新成功约1.99秒。NAS临时测试文件独占锁住内容后索引仍命中；属性变化和强制更新测试通过，测试文件已删除。缓存回归、真实窗体的文件夹成功/失败统计及取消、语言切换通过；Store原生扩展编译通过。证据artifacts/nas-update。未启动沙箱。

本机原有启用格式已切到%LOCALAPPDATA%\3DSTL\Versions\local-nas-20261030，新manager及worker已部署；原关联记录previous-bindings.json。桌面3DSTL快捷方式指向新管理器。GitHub公开包和已提交Store包尚未更新到本功能。
